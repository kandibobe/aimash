## [1.0.0] — 2026-07-29

Первый релизный тег. Не новая функциональность, а **фиксация линии**: до этого работа шла двумя
несвязанными путями — локально через git в `master`, на VPS через Hermes в `main`, — и `git
merge-base origin/main origin/master` пуст: `main` orphan-ветка, слить её git-ом нельзя в принципе.
Разведка показала, что **работающие на проде контейнеры собраны из `master`**, а git-дерево
`/opt/aimash` стояло на `main`. `master` объявлен единственной линией, `main` архивирован тегом.

### Добавлено
- **Маркер версии в образе.** `ARG GIT_SHA` → `LABEL org.opencontainers.image.revision` +
  `AIMASH_GIT_SHA` в рантайме; деплой берёт sha **после** `git reset --hard`, readiness-пинг
  админам показывает строкой «сборка». До этого вопрос «какой коммит сейчас в проде» не отвечался
  ничем: `.dockerignore` исключает `.git`, значит `docker exec … git rev-parse` не работает **по
  построению**, а снаружи оставалось только время сборки контейнера. Именно поэтому расхождение
  рантайма и дерева на сервере жило незамеченным.
- **Гард слагов моделей** (`tests/test_model_slugs.py`). `check_model_slugs` линта Hermes закрывает
  ровно `~/.hermes/config.yaml`; собственные роли бота (`llm_*` в `core/config.py`, `LLM_*` в
  `.env.example`, пресеты `/model`) не проверял никто — при том что симптом тот же (`HTTP 400 … is
  not a valid model ID`, non-retryable ⇒ бот молчит), а путь до прода короче: слаг приезжает обычным
  коммитом. Роли перечисляются через `Settings.model_fields` — новая `llm_*` попадает под гард
  фактом объявления. Нет сети ⇒ `skip` с причиной, не «зелено»; отрицательный контроль обязателен.

### Исправлено
- 🔒 **`backups/` не игнорировался git-ом.** Строка была написана как
  `backups/    # C1: авто-дампы pg_dump …`, а **git не знает trailing-комментариев**: `#` начинает
  комментарий только в начале строки. Литерал читался целиком, `git check-ignore backups/x.sql` не
  срабатывал. На VPS там лежит `pg_dump -Fc` **всей** БД, включая `audit_log` и шифрованные
  `oauth_tokens`; **репозиторий публичный** — первый же `git add -A` на сервере выложил бы дампы
  наружу (правило 5). Проверено, что не выложил: `git log --all -- backups/ '*.dump'` пуст по всей
  истории. Дыра была открыта, в неё ничего не упало.
- **Гард, который её пропускал, чинился в корне.** `tests/test_ignore_sync.py` существовал ровно для
  этого класса, но его парсер срезал inline-комментарии (`line.split("#", 1)[0]`) — то есть был
  **добрее** проверяемого движка и «видел» паттерн, которого для git не существовало. Парсер теперь
  повторяет правило git/docker дословно, отдельный тест краснеет на **само наличие** `#` внутри
  строки-паттерна, в обоих файлах.
- **Статус в `README.md`/`CLAUDE.md` противоречил `git log`.** Утверждалось «Волна 0 не закрыта,
  следующее — Волна 1», при том что в тот же вечер легли коммиты с шапками «Волна 2/3/4/5».
  Противоречие кажущееся — это две разные нумерации (см. предупреждение выше); теперь сказано явно,
  а Волна 1 расписана таблицей по шагам 1–10 вместо стрелочного списка.
- **Замер V1 снят** (29.07): `hermes version` на VPS → `Hermes Agent v0.19.0 (2026.7.20) · local
  3ef6bbd2`. Пин подтверждён живьём, три решения об объёме (`SPEC.md:225`, `:661`, `:785`)
  разблокированы. ⚠️ `deploy/hermes/OPERATIONS.md:9` и шапка `config.yaml` всё ещё говорят `v0.17`.
- **`docs/REPO_GUARDRAILS.md` — ноль входящих ссылок**, при том что это описание рубежа
  «merge в master == авто-деплой в прод». Документ, которого никто не находит, не защищает ничего.

### Изменено
- `version = "0.0.1"` → `1.0.0`.
- Блок сборки образа `aimash-bot` описан **один раз** (YAML-якорь) вместо трёх копий в `bot`,

  Фазы −1 (`deepseek/deepseek-chat`), действующая раскладка ролей — `SPEC.md` §10.1. Живым остаётся
  измеренное: Hermes-модели дали 0/11 function-calling, на этом стоит выбор модели-мозга гейтвея.

### Удалено
- `scripts/agent_demo.py`, `scripts/read_demo.py` — демо Фазы 0, перекрыты `live_smoke_*`.
  Остальные 10 файлов из плана уборки **оставлены**: проверка показала, что `exec_demo_*` не

## Пивот на ядро Hermes (2026-07-20 → 2026-07-27)

Архитектура меняется, **функциональный объём трёх ТЗ сохраняется целиком**: кнопочный интерфейс
уступает свободному тексту с подтверждением реплаем (`SPEC.md` §2). Обоснование —
`deploy/hermes/AGENTIC_VS_TZ.md` (187 требований, 160 невыполнимы чистой LLM, 0 из 40 опровергнуто).

### Волна 1 (§12) — механизм
- **Шаг 1 ✅ bot-free bootstrap** (C1, C3, C4): `core/i18n.py` + `core/texts.py`, `advisor/apply.py`,
  `scheduler/delivery.py` (порт клавиатур), `scheduler/transport.py`. Ни один из 14 пакетов ядра не
  импортирует `bot/`. Гард — разбором исходника (AST): зонд по `sys.modules` ленивый
  `from bot import ux` внутри функции не видит в принципе.
- **Шаг 1 ✅ дом планировщика**: `python -m scheduler` + сервис в compose. Владелец джоб — не
  env-флаг, а **advisory-lock роли `scheduler`**; забыли снять `SCHEDULER_IN_BOT` — проигравший
  громко отказывает, а не шлёт всё по второму разу.
- **Шаг 3 ✅ READ через MCP**: 24 READ-инструмента, включая универсальный GAQL и bot-free workflow-сервисы,
  `ensure_read_allowed`. Round-trip через Hermes доказан живьём на 15 из них; 8 добавленных 30.07 —
  только офлайн (`tests/test_mcp_read_smoke.py`). WRITE физически отсутствует (И4).
- **Шаг 4 🟡 память**: `recall_client` — PII-free контекст клиента.
- **Шаг 2 ⛔ гарды И1–И5, шаг 5 ⛔ мутации с реплай-гейтом, шаги 6–10 ⛔** — не сделаны.
  Мутации сегодня идут прежним, кнопочным путём.

### Денежный путь — серия 21.07 (своя нумерация)
- **Волна 1.3/1.4:** второй, неподделываемый бит провенанса `origin_human_turn` — штампует
  доверенный слой в момент создания черновика, аргументом не задаётся вовсе. Подтверждение
  человеком бит **не повышает**: иначе проверка тождественно истинна.
- **Волна 1.1:** реестр тиров свежести 41/41 + гейт A на вертикали мутаций.
- **Волна 4 E0:** машиночитаемый `error_code`, замок чтения.
- Распределённый стор квоты `ads_quota_ops`; ролевые ключи advisory-lock.

### Денежный путь — серия 27.07 (своя нумерация)
- **Волна 2 (§5):** распределённый размыкатель с **арендой пробы** — в half-open право на один
  пробный запрос берётся атомарным UPDATE (`rowcount == 1`, приём `ConfirmStore.claim`). Цепь
  пер-аккаунт и пер-модель. ⚠️ Осознанное исключение из правила 10: сбой стора размыкателя →
  fail-**OPEN**; размыкатель про доступность, а не про безопасность.
- **Волна 3 (§2):** event-sourcing журнала прогонов — событие у **каждой** мутации, пишется
  fail-closed **до** вызова SDK, точка эмиссии одна (`ads.mutations._require_confirmation`).
- **Волна 4 (§1):** наблюдение за применённой мутацией, режим `shadow`.
- **Волна 5 (§4):** тиры риска L1/L2/L3 — **презентационные по построению**: AST-гард запрещает
  любому модулю `ads/**` импортировать `confirm.risk`, влияние на девять проверок §2.2 невозможно,
  а не «не предусмотрено». Монотонность L1 ⊂ L2 ⊂ L3, неизвестность → L3.

### Инфраструктура пивота
- `deploy/hermes/lint_config.py` — конфиг-линт К10 (**Hermes молча игнорирует неизвестные ключи**).
  Ловит уже не только имена, но и **значения**: слаги против живого каталога OpenRouter, эндпоинты
  дефолт-модели. Три реальных случая поймано.
- `mcp_server/probe.py` + `deploy/hermes/plugins/aimash_probe/` — прибор замеров Волны 0.
- `.github/CODEOWNERS` + ранбук ruleset (`docs/REPO_GUARDRAILS.md`).
- propose-only WRITE-MCP и `confirm_by_reply` (CAS) — написаны, **в прод не выведены**: до
  подтверждения доверенного канала метаданных гейта WRITE-слой не выпускается (§15.2).

## Предпродакшн-харденинг (2026-07-04 → 2026-07-23)

- **Замок аккаунта** разведён на два чокпойнта: `ensure_allowed` (мутации, ⊆ `allowed_ceiling()`) и
  более широкий `ensure_read_allowed` + пер-пользовательский грант. **Грант чтения не открывает
  мутации.** Прод-дефолт — сентинел `all` (решение владельца 07.2026), явный список **сужает**,
  в dev/test пусто ⇒ мутаций нет вовсе (fail-closed).
- Рантайм-whitelist (`/adduser`, `/addadmin`, `/grant`), квота API на сутки (`/quota`), 2FA для
  опасных операций, kill-switch.
- Секреты: `SecretStr` в конфиге, Fernet-шифрование refresh-токенов at-rest, три рубежа редакции
  наружу (`core.logging.redact_text`, `bot.ux.err_text`), `gitleaks` в pre-commit и CI, prod
  fail-fast на отсутствие ключа шифрования и на пустой whitelist.
- Пароли БД только из `.env` через `${VAR:?}` — `docker compose` отказывает подниматься без них,
  а не поднимается со всем известным паролем.
- Автобэкап: сайдкар `backup`, `pg_dump -Fc` + ротация 14 дней. ⚠️ Локальный том — не офсайт;
  `SECRETS_ENCRYPTION_KEY` бэкапится **отдельно**, иначе `oauth_tokens` в дампе мертвы.
- Healthcheck по **свежести heartbeat**, а не по импорту модулей: зависший polling и крэш-луп
  раньше оставались «healthy».
- Авто-деплой (push `master` → зелёный CI → SSH), пост-деплойный гейт проверяет **оба** контейнера
  и ловит рост `RestartCount` (крэш-луп бывает `running` в каждый момент замера).
- Ретраи с джиттером (AWS Full Jitter) и таймауты к Google Ads SDK и OpenRouter.
