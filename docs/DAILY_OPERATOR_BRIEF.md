# Daily Operator Brief Standard

## Purpose

Normalize daily output so the system helps decisions, not just observation.

## Required format

1. **3 главных риска**
2. **3 главных возможности**
3. **1 recommended priority**
4. **1 thing to ignore today**
5. **Approvals queue count**

## Rendering rules

- worst-first ordering
- no raw dumps unless explicitly requested
- each item should cite the account/campaign and why it matters now
- if confidence is low, say so directly

## Inputs

- decision objects
- account health scores
- approvals queue size

## Non-goals

- not a mutation command
- not a full audit dump
- not a raw metrics table
