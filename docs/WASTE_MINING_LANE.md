# Waste Mining Lane

## Purpose

Separate waste mining from generic audits so it gets explicit attention and reporting.

## Scope

- search term waste
- negative keyword opportunities
- low-intent leakage
- brand contamination
- B2B/B2C mismatch

## Output

Waste lane should emit standard decision objects, not free-form observations.

## Suggested cadence

- light scan: daily or every weekday
- deeper cleanup: weekly

## Why separate lane

This class of issues often yields the cheapest performance improvement, but gets buried inside general findings.
