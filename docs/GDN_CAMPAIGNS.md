# GDN: кампания из медиа (ТЗ §11)

Создание медийной (Google Display Network) кампании из присланного в Telegram **фото**. Как и
любая мутация — **за confirm-гейтом**: бот показывает черновик и ждёт «да». Кампания создаётся в
статусе **PAUSED** (не тратит деньги до явного запуска оператором). Реализация —
[`ads/assets.py`](../ads/assets.py) (подготовка/загрузка изображений) + `apply_create_gdn_campaign`
в [`ads/mutations.py`](../ads/mutations.py); тесты — [`tests/test_gdn_campaign.py`](../tests/test_gdn_campaign.py).

## Поток
```
Фото в Telegram → КОД режет 2 кадра (1.91:1 + 1:1) → во временное хранилище по media_id
  → в proposal.params идёт ТОЛЬКО media_id (не байты) → бот показывает черновик + ✅/❌
  → на «да»: upload_image_asset (ensure_allowed) → создание PAUSED-кампании → audit-row
```

## Подготовка изображений (Pillow)
`prepare_display_images(photo_bytes)` → два JPEG-кадра, которые нужны адаптивному медийному
объявлению (RDA):
- **landscape 1.91:1** — 1200×628 (≥ маркетингового минимума Google 600×314, взято ×2 с запасом);
- **square 1:1** — 600×600 (≥ 300×300).

Кроп — **центральный** под целевую пропорцию, затем ресайз (LANCZOS), сохранение в JPEG q=88.
Не-изображение → понятный `ValueError` (тип ошибки без секретов), пользователю — дружелюбный текст.

## Где живут байты (безопасность)
Бинарь фото **не попадает** в `proposal.params`, логи или БД. Между приёмом фото и подтверждением
кадры лежат во **временных файлах** по `media_id` (`save_pending_media` → `.l.jpg` / `.s.jpg`;
переживают рестарт бота), а в `params` идёт только `media_id` (метаданные). `media_id` валидируется
как `isalnum()` — защита от path-traversal. После исполнения/отмены — `clear_pending_media`.

## Загрузка ассета и замок аккаунта
`upload_image_asset(client, customer_id, image_bytes, name)` грузит image-ассет через `AssetService`
и возвращает `resource_name`. **`ensure_allowed`** стоит и здесь (golden rule #9): ассеты грузятся
**только** в `Aimash Draft` (`7753643025`), нигде больше.

## Ограничения / заметки
- Кампания создаётся **PAUSED** — запуск только осознанной командой оператора.
- GDN-из-медиа в ТЗ помечен как опциональный/поздний; визард приёма фото — за общим confirm-гейтом.
- Политические объявления (EU) и прочие флаги SDK — best-effort, см. комментарии в `apply_create_gdn_campaign`.

Гарантии безопасности целиком — [SECURITY.md](SECURITY.md). Шаблон новой мутации — скил `new-mutation`.
