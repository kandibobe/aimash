# Раздел 19. Флоу создания рекламной кампании Google Search через Telegram
# Версия 1.0 · дополняет разделы 5, 7, 10, 11 основного ТЗ
# Дата: 2026-07-30

## 19.1 Общее описание флоу

Данный раздел описывает пошаговый сценарий создания рекламной кампании типа Google Search 
(Responsive Search Ads) через Telegram-бот. Флоу запускается кнопкой «Создание кампании» и ведёт 
менеджера через все этапы: выбор аккаунта клиента, описание кампании на естественном языке, 
автоматическое заполнение настроек, ключевые слова, создание объявления (заголовки, описания, 
display path), изображения и ассеты, финальная проверка и запуск.

Флоу полностью подчиняется ключевому принципу основного ТЗ: агент — исполнитель, а не автономный 
оптимизатор. На каждом этапе агент показывает, что именно будет создано/изменено 
(«показать и подтвердить»), и переходит дальше только после подтверждения менеджера. 
Кампания создаётся в статусе PAUSED (черновик) и запускается только по отдельной прямой команде.

### Карта этапов

| Этап | Что делает агент | Подтверждение |
|------|-----------------|---------------|
| 0. Запуск | Кнопка «Создание кампании» → выбор аккаунта клиента (MCC) | Выбор аккаунта |
| 1. Кампания | Описание словами → авто-настройки (ГЕО, бюджет, тип, ставки) | ✅ Подтвердить настройки |
| 2. Ключевые слова | Свои слова (XLSX/CSV/текст) или генерация → Discover → Google Sheets → ручная верификация | ✅ Подтвердить список |
| 3. Объявление | URL → display path → 15 заголовков → 4 описания | Поэлементно |
| 4. Изображения | Прикрепление image assets (если применимо) | ✅ / Пропустить |
| 5. Ассеты | Текущие ассеты аккаунта или создание новых | ✅ Подтвердить набор |
| 6. Ad URL options | Tracking URL, Final URL suffix, custom parameters | ✅ / Пропустить |
| 7. Финал | Сводка всего объявления → правки командой → запуск | ✅ Создать / 🚀 Запустить |

## 19.2 Этап 0. Запуск и выбор аккаунта

1. Менеджер открывает бот → в меню/клавиатуре доступна inline-кнопка «➕ Создание кампании».
2. После нажатия агент через CustomerService / customer_client получает список клиентских 
   аккаунтов, подключённых к MCC, и выводит их inline-кнопками.
3. Менеджер выбирает аккаунт клиента. Выбранный customer_id фиксируется как контекст всей сессии.
4. Агент задаёт открытый вопрос: «Опишите рекламную кампанию».

## 19.3 Этап 1. Создание кампании (описание словами → настройки)

### Извлекаемые настройки кампании

| Параметр | Источник | Пример значения |
|----------|---------|-----------------|
| Название кампании | Авто-генерация по теме | Кения · Поддержанные авто · Search |
| ГЕО (geo target) | Из описания | Кения (страна); города/радиус — опц. |
| Язык таргетинга | Из описания / по ГЕО | English, Swahili |
| Бюджет (дневной) | Из описания | $40/день |
| Тип кампании | Фиксирован флоу | Search |
| Стратегия ставок | Из цели / по аналогии | Maximize Conversions / Target CPA |
| Модель оплаты | Из цели | CPA (звонки, заявки) |
| Ср. цена за клик (CPC) | Прошлые кампании | ≈ $0,18 (по аналогии) |
| Сети | По умолчанию Search | Search; Search Partners — опц. |
| Расписание показов | По аналогии / по умолчанию | 24/7 |
| Даты запуска | Из описания / сегодня | Старт сегодня, без даты конца |

### Логика заполнения пропусков (fallback на прошлые кампании)

Если из описания не извлекается значение, агент обращается к историческим данным аккаунта 
через GAQL и берёт репрезентативное значение:
- бюджет — медиана дневного бюджета активных Search-кампаний аккаунта;
- ставка / CPC — средний CPC по схожим кампаниям или средний CPA по цели;
- тип соответствия по умолчанию, язык, расписание — наиболее частые в аккаунте.

Каждое такое поле помечается «по аналогии».

## 19.4 Этап 2. Ключевые слова

### 19.4.1 Ввод A. Менеджер передаёт ключевые слова

Способы ввода:
- Загрузка файла XLSX / CSV
- Ссылка на Google Sheets
- Вставка текстом
- Инструкция + список

Типы соответствия: Broad Match, Phrase Match (по умолчанию), Exact Match.

### 19.4.2 Ввод B. Генерация ключевых слов

Конвейер:
1. Авто-генерация 10 seed-ключей (LLM)
2. Discover new keywords через KeywordPlanIdeaService.GenerateKeywordIdeas
3. Фильтрация по релевантности (AI-слой)
4. Выгрузка в Google Sheets с пометкой релевантности
5. Ручная верификация менеджером
6. Возврат ссылки системе

## 19.5 Этап 3. Создание рекламного объявления (RSA)

### 19.5.1 URL и Display Path
1. Агент спрашивает Final URL
2. Авто-формирование Display Path (2 сегмента по 15 символов)
3. Парсинг содержимого посадочной страницы

### 19.5.2 Генерация 15 заголовков (headlines)
Авто-генерация с использованием: ключевых слов, содержимого URL, информации о бизнесе.
Лимит: 30 символов на заголовок.

### 19.5.3 Создание 4 описаний (descriptions)
Аналогично заголовкам. Лимит: 90 символов на описание.

## 19.6 Этап 4. Изображения объявления (image assets)

Image assets в Search показываются не всегда. Технические требования: 1:1 и 1.91:1, 
минимум 300×300 px, до 5120 КБ.

## 19.7 Этап 5. Ассеты объявления (assets / расширения)

### Полный перечень типов ассетов Google Search

| Тип ассета | Назначение | Лимиты |
|-----------|-----------|--------|
| Sitelinks | Ссылки на ключевые страницы | ≥ 4–6 |
| Callouts | Короткие УТП без ссылок | до 25 символов |
| Structured snippets | Категории товаров/услуг | Заголовок + ≥ 4 значения |
| Call | Кнопка звонка | Номер телефона |
| Lead form | Форма заявки | Поля формы |
| Price | Карточки с ценами | Заголовок 25 + описание 25 + цена + URL |
| Promotion | Скидки и спецпредложения | Повод, тип скидки, даты |
| App | Ссылка на установку приложения | iOS/Android |
| Location | Адрес и карта | Google Business Profile |
| Affiliate location | Где купить у партнёров | Сеть магазинов |
| Image | Визуал рядом с объявлением | 1:1 / 1.91:1 |
| Business name | Имя бренда | до 25 символов |
| Business logo | Логотип | 1:1 / 4:1 |

### Автогенерация ассетов под клиента

Источники данных:
- Контент сайта клиента (карта страниц, заголовки, офферы) — для sitelinks и snippets.
- Профиль клиента в системе (телефон, адрес, бренд, акции) — для call, location, promotion, business name/logo.
- Ключевые слова и тематика кампании — для релевантности callouts и snippets.

## 19.8 Этап 6–7. Ad URL options, финальная проверка и правки

### Шаг 6: Ad URL options
- Tracking URL (шаблон отслеживания)
- Final URL suffix
- Custom parameters

### Шаг 7: Финальная сводка и правки командой

Финальная сводка содержит:
- Кампанию и настройки
- Объявление: Final URL, display path, заголовки и описания
- Изображения и ассеты
- Ad URL options
- Кнопки: ✏️ Редактировать / ✅ Создать черновик / 🚀 Запустить

Создание: через Google Ads API → кампания, группа, RSA, ключи, ассеты в статусе PAUSED.
Запуск: только по отдельной прямой команде «Запустить».

## 19.9 Используемые методы Google Ads API (по этапам)

| Этап флоу | Сервис / ресурс Google Ads API |
|-----------|-------------------------------|
| Список аккаунтов | CustomerService + customer_client |
| Создание кампании и бюджета | CampaignService, CampaignBudgetService |
| ГЕО / язык таргетинга | CampaignCriterionService |
| Ключевые слова и минус-слова | AdGroupCriterionService |
| Discover new keywords | KeywordPlanIdeaService.GenerateKeywordIdeas |
| Выгрузка в Google Sheets | Google Sheets API |
| Группа объявлений | AdGroupService |
| RSA-объявление | AdGroupAdService |
| Изображения и ассеты | AssetService + AssetSetService / CampaignAsset |
| Данные прошлых кампаний | GoogleAdsService (GAQL) |
