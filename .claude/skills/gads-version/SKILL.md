# Версия Google Ads API и сансет

Google Ads API обновляется **ежемесячно** (с янв 2026). Мажорные версии сансетятся **~через 12 месяцев** после релиза. Бот без обслуживания сломается в течение года.

## Что делать
1. Проверить текущую версию: WebFetch/WebSearch на
   `https://developers.google.com/google-ads/api/docs/release-notes`
   и `.../docs/sunset-dates`.
2. На июнь 2026 актуальна **v24.2**; v24 сансетится ~май 2027.
3. **Пин версии** в конфиге (`GOOGLE_ADS_API_VERSION` / `google-ads.yaml`), не «последняя автоматически».
4. При апгрейде — прочитать release notes на breaking changes (миграция методов/полей).

## Правила
- Не хардкодить номер версии по всему коду — только в одном месте конфига.
- Перепроверять версию ежемесячно (заложить в обслуживание/ретейнер).
- При `RESOURCE_EXHAUSTED` / депрекейте — сверяться с докой, а не гадать.
